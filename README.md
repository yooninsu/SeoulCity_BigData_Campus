# 서울시 행정동별 침수 요인 분석과 맞춤형 대비책 제안

> 🏆 **2023 서울특별시 빅데이터 캠퍼스 공모전 최우수상**
> 도시 환경·인구 데이터로 "비가 많이 오는 곳"이 아니라 "실제로 잠기는 곳"과 그 이유를 찾은 프로젝트

`Python` `scikit-learn` `statsmodels` `QGIS` · 4인 팀 · 2023.09 ~ 2023.11

---

## 1. 문제

- 서울시 **누적 강수량 상위 5개 구**와 **침수 발생 상위 5개 구**는 서초구를 빼면 겹치지 않았습니다.
  → 강수량만으로는 침수를 설명할 수 없습니다.
- 서울시가 지정한 **자연재해위험개선지구**도 실제 침수 발생 지역과 일치하지 않았습니다.
- 그래서 질문을 이렇게 바꿨습니다.
  1. 어떤 요인이 **침수 발생 여부**를 결정하는가?
  2. 침수가 나는 지역에서는 어떤 요인이 **침수 빈도**를 결정하는가?
  3. 지역 유형별로 원인이 다르다면, **유형별로 어떤 대비책**이 필요한가?

## 2. 데이터

서울시 빅데이터 캠퍼스와 공공 데이터를 **행정동 단위**로 집계해 하나의 분석 테이블로 만들었습니다.

| 구분 | 데이터 |
|---|---|
| 강우 · 침수 | 일별 강우량(구 단위), 침수흔적도(~2022), 집중호우 발생 횟수 |
| 지형 · 수문 | 수치표고모델(평균 고도·경사도), 배수등급도, 하천 경계·하천까지 거리, 제방·수문·암거, 빗물펌프장 |
| 도시 인프라 | 건물 공간데이터, 건축물대장(노후·지하 건물), 도로구간, 녹지 면적 |
| 사회 · 경제 | 인구(밀도, 고령·장애·기초생활수급), 상권분석(소득·소비) |

## 3. 분석 과정

```
데이터 수집·전처리 → ① 침수 여부 결정 요인 → ② 침수 빈도 유형화 → ③ 유형별 요인 분석 → ④ 대비책
```

**① 침수 발생 여부: 어떤 요인이 중요한가**
- T-test로 침수 지역과 비침수 지역 간 차이가 유의한 변수를 골랐습니다.
- Random Forest, SVC, KNN, Logistic Regression을 Random/Grid Search로 튜닝해 비교했습니다.

| 모델 | Accuracy |
|---|---|
| **Random Forest** | **0.744** |
| SVC | 0.725 |
| KNN | 0.710 |
| Logistic Regression | 0.700 |

- 가장 정확도가 높은 Random Forest의 information gain으로 주요 변수를 확인했습니다. 상위 변수는 도로·건물 면적 비율, 면적당 지하건물 수, 녹지 면적 비율, 평균 시우량 순이었습니다.

**② 침수 빈도: 서울을 하나로 보지 않기**
- 설명변수가 13개라 차원의 저주를 피하려고 PCA로 줄였습니다. 주성분 3개가 전체 분산의 63.7%를 설명했습니다.
- K-Means(Elbow method로 k=3)와 DBSCAN(KNN으로 eps 탐색)을 비교했고, 실루엣 계수가 더 높은 **K-Means로 행정동을 3개 유형**으로 나눴습니다.

**③ 유형별 침수 빈도 요인**
- 군집마다 의사결정나무 회귀와 다중선형회귀로 침수 빈도를 결정하는 변수를 찾았습니다.

| 유형 | 주요 요인 | 해석 |
|---|---|---|
| 그룹 1 | 인구밀도, 도로율, 하천까지 거리 | 과도한 도시화로 불투수면이 늘어난 지역 |
| 그룹 2 | 면적당 시우량, 소득, 도로율, 장애인 비율 | 강한 비를 처리할 배수 시설 자체가 부족한 지역 |
| 그룹 3 | 도로율, 평균 경사도, 하천까지 거리, 배수등급 | 개발된 도시에서 배수시설 관리가 미흡한 지역 |

## 4. 결과와 제안

- 행정동별 **침수 유형 지도**를 만들어 현재 위험지구 지정과 실제 위험 지역의 차이를 보여줬습니다.
- 유형별로 다른 대비책을 제안했습니다.
  - **불투수면 문제(그룹 1):** 도로 물막이판, 빗물받이 확충
  - **배수 시설 부족(그룹 2):** 빗물펌프장 설치, 투수 포장과 도시 녹화
  - **배수 관리 미흡(그룹 3):** 노후 하수관거 정비, 빗물 저류조
- 같은 유형으로 묶인 지역끼리 침수 대응 경험을 공유할 수 있는 근거를 만들었습니다.
